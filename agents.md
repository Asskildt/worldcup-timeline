# AI Agent Guide – em28 (UEFA Euro 2028)

## Project overview

**What is this?** — UEFA Euro 2028 site covering the full road to the tournament: Nations League 2026–27, EM-kvalifisering 2027, and the final tournament in UK & Ireland (June–July 2028). Static website with Norwegian time (CEST), hosted as a sub-project under `asskildt.eu`.

**Tab structure (current priority):**
1. **Nations League** — League A groups + standings (Norges gruppe: Portugal, Danmark, Norge, Wales)
2. **NL-kamper** — Fixture list for Group A4 (Norway's group)
3. **Kvalik** — EM-kvalifisering info (pre-draw placeholder until Dec 2026)
4. **Kvalik-kamper** — Match schedule (available after draw)
5. **EM 2028 ▾** (under "Mer"-knapp) — Tidslinje, Tabell, Grupper, Sluttspill, Arenaer

**Features:**
- Six EM views: Timeline/Grid, Table, Groups, KO bracket, Arenas, Stats
- Nations League standings and fixtures
- Qualifying info with format details
- Favorites filter and Norway highlighting
- Host country flags (England, Scotland, Wales, Ireland) in the header
- Theme toggle (system / light / dark)
- Timezone selector (8 options, auto-detected)
- Language selector (Norwegian / English)

## Tech stack

- **Hosting:** Static (no server, no database)
- **Styling:** Vanilla CSS with CSS custom properties (design tokens)
- **Fonts:** Space Mono (headings/labels), Inter (body) via Google Fonts
- **Icons:** Bootstrap Icons
- **Flags:** lipis/flag-icons SVG sprite, generated by `build.js` from `src/flag-svgs/`
- **JavaScript:** Vanilla JS, no framework
- **Data:** Static in `data.js` (generated from JSON sources by build.js)

## Data sources and future integration

### openfootball (GitHub)
Primary community data source. Format: structured `.txt` files + JSON API.

| Data | Repo | File/Path | Status | When available |
|------|------|-----------|--------|----------------|
| EM 2028 matches | `openfootball/euro` | `2028--united_kingdom-ireland/euro.txt` | Position codes only (A1 v A2) | Teams filled after draw Dec 2027 |
| NL 2026–27 | `openfootball/internationals` | `uefa_nations_league/2026_*.txt` | Not created yet | Expected Sept 2026 when season starts |
| EM qualifying | `openfootball/internationals` | `uefa_euro_qualification/2027_*.txt` | Not created yet | Expected after draw Dec 2026 |

### openfootball `.txt` format (Football.TXT)

```
= Tournament Name Year
# metadata comments
Thu Mar 20
  Team1                2-0 Team2                   @ City, Country
     (Scorer1 12' Scorer2 45';
      Scorer3 78')
Sun Mar 23
  Team3                1-1 Team4                   @ City, Country   [Team3 wins on penalties]
```

Key patterns:
- Date line: `Day Month Day` (e.g. `Thu Mar 20`)
- Match: `  Team1    score Team2    @ Venue`
- Goals: `     (scorer minute'; scorer minute')` — semicolon separates team1/team2 goals
- Penalties: `[Team wins on penalties]` appended to score line
- Extra time scores included in goal list

### openfootball JSON format (worldcup.json)

```json
{
  "round": "Matchday 1",
  "date": "2026-06-11",
  "time": "13:00 UTC-6",
  "team1": "Mexico",
  "team2": "South Africa",
  "score": { "ft": [2, 0], "ht": [1, 0] },
  "goals1": [{ "name": "Player", "minute": "9" }],
  "goals2": [],
  "group": "Group A",
  "ground": "Mexico City"
}
```

### Integration plan

1. **NL 2026–27 (Sept 2026):** When `openfootball/internationals` adds `2026_uefa_nations_league.txt`, parse it to update `nations-league.json` with results after each matchday.
2. **EM qualifying draw (Dec 2026):** Update `qualifying.json` with groups and teams once drawn.
3. **EM qualifying matches (Mar–Nov 2027):** Parse results from openfootball when available.
4. **EM draw (Dec 2027):** Replace position codes in `matches.json` with actual team names. Update `teams.json` with group assignments.
5. **EM 2028 live:** If openfootball provides a JSON feed (like `worldcup.json`), point `API_URL` at it for live results.

**Fallback:** If openfootball doesn't cover NL/qualifying, manually update JSON files after each matchday. The site works entirely statically.

## EM 2028 format

- **Groups:** 6 groups (A–F) with 4 teams each = 24 teams total
- **Group matches:** 36 (3 matchdays per group)
- **KO rounds:** R16 (8), QF (4), SF (2), Final (1) = 15 KO matches
- **Best third-placed teams:** 4 of 6 advance to R16
- **Total:** 51 matches
- **Matches use position codes** (A1, A2, 1A, 2B, W37 etc.) until teams are drawn

## Nations League 2026–27 (League A)

- **Format:** 4 groups of 4 teams, home-and-away round-robin (6 matches each)
- **Advancement:** Top 2 → quarter-finals (March 2027), QF winners → Finals (June 2027)
- **Relegation:** 4th-placed teams drop to League B, 3rd plays relegation play-off
- **EM link:** NL results feed into EM qualifying play-off seedings

**Groups:**
- A1: France, Italy, Belgium, Turkey
- A2: Germany, Netherlands, Serbia, Greece
- A3: Spain, Croatia, England, Czech Republic
- A4: **Portugal, Denmark, Norway, Wales** ← Norges gruppe

**Matchdays:** Sept 24–26, Sept 27–29, Sept 30–Oct 3, Oct 4–6, Nov 12–14, Nov 15–17

## Design system

### Theme toggle
`system` / `dark` / `light` — stored in `localStorage` key `theme`.

### Typography
- **Headings/Labels:** Space Mono, uppercase, letter-spacing
- **Body:** Inter, normal weight

## Rules for changes

1. **Always edit in `src/`** — never in `dist/`. Run `node build.js` after changes.
2. **Data lives in JSON files** — `src/data/*.json` is the source of truth.
3. **Static hosting** — No server-side code.
4. **No emoji in UI** — use Bootstrap Icons or flag-icons SVG sprites.
5. **Flag system** — `src/flag-svgs/{cc}.svg` from [flagicons.lipis.dev](https://flagicons.lipis.dev).
6. **Mobile-first** — Design for mobile first, scale up for desktop.
7. **EM matches use position codes** — Don't add speculative team names.
